# Work flows

There is easy to get tangled up in the techincal stuff around Git, Git-tools, and technical issues but there is some tasks that no tools can help with. Human habits.  

## Good habits

* Commit early
* Push often
* Pull often
* Pull before pushing
* The commit message

## Bad habits

* Commits too large.
* Bad commit messages.
* Leave your project in a dirty state.
* Do not push commits.
