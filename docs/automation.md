Different operations create fire off different hooks/events. This allows you to trigger different actions related to the changes made to a repository.

client-side:
```txt
pre-commit
prepare-commit-msg
commit-msg
post-commit

post-checkout
pre-rebase
```

server-side:
```
pre-receive
update
post-receive
```
